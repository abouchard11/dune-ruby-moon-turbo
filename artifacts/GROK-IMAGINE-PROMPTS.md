# MidnightDev — Grok Imagine copy-paste prompts

Image models scramble labels. The live **Midnight Atlas** in preview is the accurate picture. Use these only if you want a mood poster.

Paste **one prompt per generation**. Aspect **16:9**.

**Palette:** Ground `#0B0D10` · Gold rail `#C9A227` · Cyan `#7FD1D4` · Type off-white

**Global negatives (append if it drifts):**
No cartoon brain, no neurons, no photoreal people, no robots, no circuit-board filler, no other-company logos, no unreadably tiny lorem ipsum, no mesh of circular arrows between repos.

## Variants if a frame comes back mushy

- **Tighter type:** All labels must be large enough to read at a glance. Prefer fewer words, larger type. No decorative micro-text.
- **Portrait phone lockup:** Change canvas to 9:16, put only the Hermes six-question list, drop the Dozen graph.
- **Whiteboard reconstruction:** Redraw as a single black-on-white engineering whiteboard photo, thick marker, no color except one red box around ACCEPT / POST / PAY.

---

## What these pictures are not allowed to imply

- Repos do not all edit each other. Ownership is **directed**: AGO → MAS → reasoning → Hermes.
- The brain is **four stores + four tiers**, not one vector database.
- Self-improvement is **draft → lint → inbox → human**. The model never owns the skill-mutation edge.
